## Topics Explored

1. **IPOS Cycle:** How input flows through the CPU/memory to produce output and persistent storage.
2. **Terminal Operations:** Navigation, file operations, permissions (`r`, `w`, `x`), flags, and pipes.
3. **Operating Systems:** Process management, PIDs, storage inspection, and core OS services.
4. **Execution Models:** Key differences between compiled languages (like C) and interpreted languages (like Python).
5. **Data Representation:** Converting between decimal, binary, and hexadecimal, plus ASCII and UTF-8 encoding.
6. **Version Control:** Branching, commits, remote pushing, and merging via GitHub Pull Requests.
7. **Networking:** DNS lookups, latency testing, router functions, and the 7-step HTTP/HTTPS lifecycle.

## How to Run the Number Converter

The Python number converter is located inside the `mission-05-numbers-data` folder. To run it:

1. Open your Terminal and navigate to the project directory:
   ```bash
   cd ~/Downloads/digital-detective-8443/mission-05-numbers-data
   ```
2. Run the script using Python 3:
   ```bash
   python3 number_converter.py
   ```
3. Enter any positive decimal number when prompted (e.g., `25`) to view its binary and hexadecimal equivalents.
